# Echoids wiki

Echoids is a creature-collecting game for the Flipper Zero. Wild echoids live in WiFi
access points, and Bluetooth devices drop the shards you craft with. See the
[README](../../README.md) for setup, controls and crafting.

## Pages

- **[Types](Types.md)**: the 8 types, the type cycle, the matchup chart, strengths and
  weaknesses, and battle tips.
- **[Types and Moves](Types-and-Moves.md)**: every move, who can learn it, and each
  species' full learnset.

The Types and Types and Moves pages are generated from the game code by `tools/gen_wiki.c`,
so they always match the game.
